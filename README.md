# 英語話劇台詞接龍練習器

幫助話劇組練習「聽到上一句 → 立刻知道下一句是誰、講什麼」。  
支援手機與電腦，成績與錯題可雲端同步。

網站：https://lucas981020.github.io/English-Drama-Chain-Game/

---

## 第一次使用

1. 打開網站後，**先設定暱稱**（會綁定排行榜與錯題本，請固定使用同一個）
2. 之後即可開始練習

若要更換暱稱：首頁點目前暱稱旁的 ✏️ 即可重設。

---

## 功能一覽

| 功能 | 說明 |
|------|------|
| 🎯 練習 | 接龍答題（角色 + 台詞） |
| 📖 劇本 | 瀏覽完整台詞，可勾選角色高亮 |
| 📕 錯題 | 雲端保存的錯誤紀錄 |
| 🏆 排行 | 班級即時排行榜（需密碼） |

---

## 練習設定

### 1. 角色範圍

- **我的角色**：只出「下一句是你負責角色」的題；不用選角色，直接答台詞  
- **全角色**：所有台詞都可能出現；先選「下一句是誰」，再答台詞  

> 💡 排行榜**只統計「全角色」**，避免各角色台詞量不同造成不公平。

### 2. 作答模式

- **四選一**：從四個選項中選出正確下一句（較快）
- **整句輸入**：自己打出完整台詞（較難）  
  - 大小寫、標點、空格不計  
  - 拼錯時可能出現**單字**建議（不會提示整句）  
  - 與正確答案非常接近時，會直接判對

### 3. 題數

可選：**10 / 25 / 50 / 全部**

### 4. 出題範圍

可複選 Act I～VIII，至少選一個。

---

## 答題流程

每一題會顯示**上一句**（含講者）。

1. **全角色模式**  
   - 先選「下一句是誰」（合講可複選）  
   - 再答下一句台詞  

2. **我的角色模式**  
   - 直接答下一句台詞（一定是自己的角色）

若上一句是該 Act 的最後一句，旁會標示 **· Act ends**，表示答案是**下一幕第一句**。

---

## 排行榜規則

- **班級密碼**：`201drama`（首次查看或上傳時輸入）
- **計分條件**（需同時滿足）：
  - 範圍 = **全角色**
  - 題數 = **50** 或 **全部**
- **榜單種類**（兩種分開排）：
  - 四選一
  - 整句輸入
- **排序方式**：
  1. 正確率高者在前  
  2. 正確率相同 → 總作答時間短者在前  
- **顯示內容**：正確率 %、正確數/總小題數、作答時間  

> 10 題、25 題，或「我的角色」模式：**可練習，但不計入排行榜**。

---

## 錯題本

- 依暱稱存在雲端，換裝置只要用同一暱稱即可看到  
- 分「角色錯誤」與「台詞錯誤」  
- 數字徽章 = 該題累積錯誤次數  

---

## 劇本瀏覽

- 可勾選一個或多個角色，該角色台詞會高亮  
- 方便對稿、找自己的段落  

---

## 使用建議

1. 剛開始：選「我的角色」+「四選一」+ 較少題數  
2. 熟悉後：改「全角色」+「四選一」+ 50 題（可上榜）  
3. 衝刺背誦：「全角色」+「整句輸入」+ 50 題／全部  
4. 定期看錯題本，針對常錯句加強  

---

## 注意事項

- 請使用**固定暱稱**，否則排行榜與錯題會分散  
- 排行榜與錯題需要網路（Firebase）  
- 正式演出稿若有改字，請把新稿提供給維護者更新題庫
